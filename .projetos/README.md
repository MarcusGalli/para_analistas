# .projetos/

Clones git dos projetos em que voce trabalha. **Conteudo ignorado pelo git** deste repositorio.

```bash
git clone <url-do-projeto> .projetos/<nome-do-projeto>
```

Depois peca ao Claude: *"registre o projeto <nome> no contexto"* — ele le o projeto e preenche
[`contexto/PROJETOS.md`](../contexto/PROJETOS.md).
